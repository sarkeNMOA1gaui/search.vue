# alpaca-addons

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Utility library demonstrating Java 8 stream operations and functional pipeline patterns.

## cnodejs-react
- `mvn clean install`
- `mvn test`
- `java -jar target/alpaca-addons-1.0.jar` — press `ctrl+c` to stop
